Export as .mogrt

A .mogrt is a Motion Graphics template: Premiere Pro editors can change the text and colours in the Essential Graphics panel. Only After Effects can make one, so Thirdline will:

  1. open After Effects (change…) and start a new project,
  2. rebuild this lower third there as an editable comp,
  3. ask where to save it, then save the .aep and export the .mogrt next to it.

Save your work in After Effects first. Starting a new project closes the one that’s open. If it has unsaved changes, After Effects will ask whether to save them; you can also save and close it yourself before continuing.
